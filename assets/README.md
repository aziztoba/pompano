# Rose-and-ribbon artwork

File: `assets/rose-still-life.png` (1536 × 1024 PNG).

Created for this invitation using the built-in image generation tool. It supplies the floral still life behind the interactive HTML envelope. The ribbon, lettering, controls, and invitation layout are implemented in code. On phones, CSS masks compose the same photograph into a top-right ribbon and bottom-left rose arrangement.

## Final generation prompt

Use case: photorealistic-natural. Asset type: decorative full-bleed background for an elegant cozy engagement invitation website. Create a high-end editorial still life, landscape 3:2 composition, photographed directly overhead. Warm pale pink and creamy blush linen background, beautifully folded soft blush silk gathered only around the far edges. At bottom left a lush cluster of deep burgundy red garden roses with a few pale pink roses, cropped by frame. At upper right a loose thin dark cherry red satin ribbon curling into a graceful bow, and one cropped blush rose. A few tiny loose rose petals. Gentle afternoon sunlight from upper left, delicate organic shadows, exquisite real petal and silk texture, restrained fine film grain, intimate, warm and romantic. The central 65 percent must stay empty pale blush linen with very little texture, for live HTML invitation content. Edge florals should occupy at most 25 percent. No text, no letters, no people, no cards, no envelope, no watermarks. Photographic, sophisticated analog editorial styling, not plastic 3D, not cartoon.
